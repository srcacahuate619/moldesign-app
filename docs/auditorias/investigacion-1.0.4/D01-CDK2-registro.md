Se reutilizan las diez muestras archivadas de CDK2 humana, Chai-1 0.6.1 y semilla 42. Se fija 1HCL cadena A, CDK2 humano apo, para comparar la condición apo. Se fija 1H1Q cadena A como referencia del bolsillo usado por OpenFF para cdk2. 1H1Q contiene ciclina A, Thr160 fosforilada y NU6094 CCD 2A6, distinto del ligando enviado a Chai-1. Se mostrará además la diferencia de usar ambas referencias para cada predicción. Son dos geometrías experimentales históricas anteriores al corte de 2021-01-12 y no cuentan como validación fuera de entrenamiento.
