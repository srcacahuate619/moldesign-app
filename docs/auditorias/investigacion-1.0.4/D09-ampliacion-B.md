La procedencia de la instancia se comprueba por centroide, residuo y cadena, y el código completo por el depósito. Este chequeo mide identidad geométrica de la caja. La capacidad de reconstruir poses y detectar mecanismos requiere sus propios controles.

Para repetir desde la raíz, ejecutar este bloque con `python-embed\python.exe -I -` y comparar los 33 centroides, además de guardar los SHA-256 como referencia de los bytes locales. Los depósitos del PDB se distribuyen bajo CC0 1.0. [Política de wwPDB](https://www.wwpdb.org/about/usage-policies)

```python
import gzip, hashlib, json, math
from pathlib import Path

root = Path("data/targets")
panel = json.loads(Path("backend/data/anti_dianas_bowes44.json").read_bytes())["dianas"]
pilot = {"HTR2B", "KCNH2", "SCN5A", "CACNA1C", "GABRA1", "PTGS2",
         "PDE3A", "CHRNA4", None}
for row in panel:
    if row["gen"] in pilot or not row.get("pdb_id"):
        continue
    pdb = row["pdb_id"]
    data = (root / f"{pdb}.pdb.gz").read_bytes()
    residues = {}
    for line in gzip.decompress(data).decode("ascii", "replace").splitlines():
        if line.startswith("HETATM") and line[16] in " A" and line[76:78].strip() not in {"H", "D"}:
            point = tuple(float(line[i:i+8]) for i in (30, 38, 46))
            residues.setdefault(line[17:27], []).append(point)
    candidates = []
    for key, points in residues.items():
        centroid = tuple(math.fsum(axis) / len(points) for axis in zip(*points))
        candidates.append((math.dist(centroid, row["center"]), key))
    distance, key = min(candidates)
    assert distance < .001, (pdb, distance)
    print(pdb, key, f"{distance:.6f}", hashlib.sha256(data).hexdigest())
```
