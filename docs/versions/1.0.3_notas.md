# MolDesign 1.0.3.0 — cambios desde 1.0.2.0

**Estado: publicada en Microsoft Store.** La base es el segundo paquete 1.0.2.0, construido desde `dd09e229`. El corte del parche es `bef67706`. El registro del propietario sitúa la publicación el 22 de octubre de 2026. [Registro del hotfix](1.0.3_cambios.md)

## Qué entra (resumen)

- **Molcy completa el trabajo fuera de la carpeta protegida de Store.** Blender podía terminar los fotogramas y fallar al guardar la escena, cuando Molecular Nodes intentaba volver a la carpeta del backend dentro de `WindowsApps`. El vídeo y las fotos se lanzan desde la carpeta de cada trabajo. Las comprobaciones y la instalación de la extensión usan el área de datos de Molcy. En Windows, la cancelación también fija un directorio accesible para `taskkill`. El cambio corrige la ruta que provocaba el fallo de permisos antes de producir el MP4.
- **Se recuperan el halo del título y el sellado del vídeo.** En la primera prueba del parche, el MP4 ya se creaba pero PowerShell recibía «Acceso denegado» al arrancar el Python del paquete para las dos tareas finales. Molcy copia unos 35 MiB de intérprete y Pillow a sus datos locales. Reutiliza una copia completa identificada por el tamaño y la fecha de los archivos de origen y rehace una copia interrumpida. El vídeo comprueba primero el espacio disponible. Las fotos usan el mismo intérprete auxiliar. El cambio permite completar los pasos que antes dejaban el trabajo como fallido aun con el MP4 presente.
- **Meeko identifica el residuo cuando sus átomos no son contiguos.** Si el preparador informa ese fallo, el aviso de subida incluye la cadena y el número del residuo, en español o inglés. La persona puede reordenar sus átomos o subir el receptor preparado como PDBQT. La corrección actúa en el diagnóstico de subida.
- **«Detalles del caso» se puede cerrar con el teclado.** El panel comienza bajo la barra de navegación para que se vea el botón de cierre. Escape funciona también cuando el foco está fuera del panel y se conserva la navegación interna con Tab. El usuario puede regresar al caso sin tener que mover primero el foco.

## Alcance y verificación

- La prueba de la aplicación instalada reprodujo el fallo de la carpeta de trabajo y luego el fallo del Python auxiliar original. Con la copia corregida se comprobó fuera de la app instalada que Pillow arranca, el script de sellado genera la huella de un MP4 real y el contraste produce el halo en un fotograma de prueba. El registro histórico no conserva una comprobación completa del paquete final instalado, ni el resultado de WACK o de la VM. [Diagnóstico y alcance de pruebas](1.0.3_hotfix.md)

- **Repositorio público.** La instantánea pública `0d06f814` contiene el registro histórico del parche y ya declara 1.0.4 en desarrollo. `bef67706` identifica el corte que documenta el paquete de Store.
