# Productor MET-01-R1

`python scripts/medir_met01r1.py <comando>` ejecuta `met01r1.py` desde aquí.
Es el productor de MET-01 con las sustituciones contadas de `CAMBIOS_DESDE_MET01.md`;
`capsula.mjs` es la de MET-01 byte a byte. El producto ejecutado es backend/ de 9ce8b104,
y el guardián del arnés exige que no difiera de esa base. Prerregistro: `entrada/protocolo.json`.
